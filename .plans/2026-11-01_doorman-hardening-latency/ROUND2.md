### 3. Security findings, each with tests
Medium:
1. M1, unbounded `read_line` on a 0666 socket (daemon/src/ipc_policy.rs:271).
   Use a bounded read (cap line length, e.g. 64 KiB, via `take`), drop the
   connection on overflow, add a per-uid connection limit. Tests: oversize
   line without newline is rejected and memory stays bounded; per-uid limit.
2. M2, liveness not bound to identity across frames (daemon/src/ipc.rs:501-542
   vs daemon/src/pipeline/sequential.rs:107-119). Liveness is evaluated on the
   first quality frames only, while later frames are scored for similarity
   only, so a live face followed by a photo can be accepted. Require liveness
   evidence on the same frames or track that produce the accepted match, or
   re-check liveness on the deciding frames. Add a swap test with synthetic
   frames (live frames, then photo frames must not accept).
3. M3, embeddings save (daemon/src/storage.rs:122-133). Create the temp file
   with mode 0600 at creation (OpenOptions mode), fsync the file, rename, fsync
   the directory. Verify StateDirectoryMode and directory perms are 0700 in the
   unit and in the installer (the chmod branch only runs as root; the service
   runs unprivileged). Tests: mode of the temp file at creation, resulting
   file mode 0600.
4. M4, v1 to v2 migration has no backup (daemon/src/storage.rs:116-124). Write
   `embeddings.bin.v1.bak` (0600) before the first v2 write, never overwrite an
   existing backup, document rollback. Tests: backup created once, not
   overwritten on a second write.

Low, fix where trivial:
5. Missing `protocol_version` is treated as current (shared/src/lib.rs:8-10,
   daemon/src/ipc_policy.rs:188). Must not become a bypass once v2 exists:
   document it now, reject missing version once v2 exists.
6. PAM callers all run as uid 0 and share one rate-limit bucket
   (daemon/src/ipc_policy.rs:220). One user must not be able to exhaust the
   shared bucket; key the state per target user for PAM callers.
7. `dataset purge` must not follow symlinks (daemon/src/dataset_purge.rs,
   bin/doorman.rs). Use symlink_metadata or O_NOFOLLOW, or canonicalize and
   check the path is inside the data dir. Test with a symlinked `captures`.
8. `scripts/doorman-sudo-pam.sh --i-have-a-root-shell-open` is only a flag
   string. Either verify a second root session exists (another root tty or pts
   via `who` or `loginctl`) or rename the flag so it is clearly only an
   acknowledgement.

Other Low items from the review (optional, lower priority): WaitForMatch
retries are not counted per attempt by the limiter; rate-limit and suspension
state resets on restart; no max frame age outside the strict profile; PAM
module does not verify the daemon identity via SO_PEERCRED; socket mode set
after bind; locker identity check by name only; `bind_socket` umask.
